# Login

It starts with a UI for a login page, and the login page works, technically. You need to enter the correct username and password. After 1 failed attempt, check the console and you get to see what the username and password is to actually log in. After logging in, you get to see what the main content is. 

# Dependencies
I installed React Router Dom, and you most likely need to type `npm install` in the login directory to install the necessary dependencies after cloning the repository.
